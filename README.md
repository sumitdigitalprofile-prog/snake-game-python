# 🐍 Snake Game

A simple 2D Snake Game built using **Python** and **Pygame**.

The project was created to learn the basics of game development with Python, including game loops, keyboard controls, collision detection, movement, and object rendering.

## 🎮 Features

- 🐍 Snake movement
- 🍎 Random food generation
- 📈 Snake grows after eating food
- 💥 Wall collision detection
- 💥 Self-collision detection
- 🎯 Keyboard controls
- 🖥️ Simple 2D game window

## 🕹️ Controls

| Key | Action |
|---|---|
| ⬆️ Up Arrow | Move Up |
| ⬇️ Down Arrow | Move Down |
| ⬅️ Left Arrow | Move Left |
| ➡️ Right Arrow | Move Right |
| ❌ Close Window | Exit Game |

## 🛠️ Technologies Used

- **Python**
- **Pygame**
